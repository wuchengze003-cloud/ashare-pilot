# V2 赛马结果作废说明

本目录保留 2026-07-28 生成的 V2 日线与分钟赛马产物，仅用于审计，不得作为生产策略证据。

复核发现，V2 特征面板中的市场聚合和横截面排名混入了当日历史股票池之外的证券，形成 point-in-time 污染。污染会改变市场广度、行业相对强弱和候选排序，因此原结果不能用于晋级、调参或生产信号。

修复后使用 feature version 5、锁定的 V3 研究合同和固定数据面板重新进行了一次性样本外验收。V3 最终结论以 `research/runtime/strategy-race/daily-report.json` 为准；旧产物不得回灌生产运行目录。
