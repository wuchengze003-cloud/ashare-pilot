**角色**：股票池_策略师_B1
**性质**：仅为调整方案（proposal），**未修改 `web/data/universe.json`**。是否落地由 Codex/所有者决策。
**输入**：`macro-brief.md`（19 主题宏观/产业事件强度）、`pool-performance-1m.md/.json`（123 只成分股近一月行情 + 池外 30 只初筛候选）、`web/data/universe.json`（现行池，updated_at=2026-07-02）。

## 0. Schema 理解与设计前提

现行 universe.json 的关键机制：

- `pool_tier`：`core`（正式层，参与策略信号生成）/ `watch`（观察层，通常配 `strategy_until` 截止日与 `review_reason`，不进入当期策略）。
- `strategy_from` / `strategy_until`：点时生效区间，保证股票池变更可回溯、可重放（point-in-time）。
- `previous_theme` + `theme_effective_from`：主题迁移留痕。
- **股票池定位：它是"观察与信号生成的范围"，不是买入建议。** 这是本次处理"高景气+暴跌"矛盾的总原则（见第 3 节）。

本方案所有新增/变更条目若落地，均应带 `strategy_from: "2026-07-23"`（或实际落地日），降级/剔除条目以 `strategy_until` 截止而非物理删除，保留历史可追溯性。

## 1. 调整规则（三维评分 → 四档动作）

### 1.1 三个输入维度

| 维度 | 来源 | 量化 |
|---|---|---|
| **E 景气强度** | macro-brief 主题强度评级 | 1–5 分；5 = 涨价/业绩/订单三重确认 |
| **P 行情强弱** | pool-performance-1m | 区间涨跌幅、超额收益（vs 沪深300 -3.89%）、最大回撤、成交额趋势 |
| **V 验证状态** | universe.json 既有 `review_reason` + 窗口内表现 | watch 股的"待验证假设"是否被行情/事件证实或证伪 |

### 1.2 动作规则（阈值化，保证可复算）

| 动作 | 触发条件（同时满足，除非注明） |
|---|---|
| **剔除（remove）** | 现任 `watch` 且满足任一：① 区间跌幅 < -35%（验证彻底失败）；② E ≤ 3 且跌幅 < -20% 且成交额趋势 < -30%（弱主题+弱行情+关注度流失）；③ 原 `review_reason` 的待验证假设在窗口内无任何正面证据且区间收益为负 |
| **core → watch（降级）** | 满足任一：① 区间跌幅 < -30% 且成交额趋势 < -30%（价格+流动性双杀）；② 区间跌幅 < -40%（单阈值深度回撤）；③ 重大个股性利空事件（非行业性），不确定性未消除；④ E ≤ 3 且区间跌幅 < -35% |
| **豁免降级（保留 core）** | 主题内不可替代龙头（全球份额/订单直接确认，如中际旭创、新易盛、兆易创新、香农芯创、立讯精密），即使触发阈值也保留 core，但打"拥挤回撤"状态标签（见第 3 节） |
| **watch → core（升级）** | 区间涨幅 > +5%（正超额）且 E ≥ 4 且成交额趋势 > 0，且原 `review_reason` 的疑点被行情/公告证据解除 |
| **新入（add）** | 池外候选：行业与既有主题直接相关（非初筛标签的牵强归类），E ≥ 4，近一月涨幅 > 0 且日均成交额 ≥ 5 亿；**一律 watch 起步**，满一个观察期方可升 core |

**原则**：主题级 E 决定"这个方向还值不值得看"，个股级 P/V 决定"这只股票在池内用什么身份看"。主题暴跌本身不触发主题摘除；主题 E 降至 ≤2 才考虑整主题降级（本窗口无此情形）。

## 2. 关键矛盾处理：高景气 + 高拥挤回撤（光模块 / AI-PCB / 存储）

### 2.1 矛盾事实

| 主题 | 宏观强度 E | 窗口等权涨幅 | 胜率 |
|---|---|---|---|
| 光模块 | 5（订单覆盖全年、新易盛业绩翻倍） | **-33.76%** | 0% |
| AI-PCB | 5（覆铜板涨价、扩产潮） | **-30.46%** | 7% |
| 存储/HBM | 5（DRAM +53-63%、长鑫 IPO、海力士上市） | **-29.83%** | 0% |

基本面利好与股价暴跌并存。诱因主要是 7/17 黑色周四（Kimi K3 冲击 AI 估值叙事 + 费半技术性熊市）引发的拥挤交易瓦解，而非景气证伪。

### 2.2 规则结论

1. **`pool_tier` 不表达景气度，也不表达择时。** 它只表达"是否纳入信号生成范围"。因此主题级景气强 → 主题保留在池内且维持 core 阵容；个股是否降级只看个股层面的价格/流动性/事件证据，不看主题层面景气。
2. **不建议新增第三层 tier（如 `core-distressed`）**。改动 schema 会牵连 web 打分器与 research 回放的全部假设，收益不成比例。替代方案：在方案层引入**非 schema 状态标签 `crowded_drawdown`**（高景气 + 区间跌幅 < -25% + 胜率 ≤ 20%），建议由打分器侧以单独配置文件实现，用于信号降权或延长确认，**universe.json 本身不动**。
3. **执行结果**：三大主题中，绝对龙头（订单/业绩直接确认）保留 core 并打标签；边缘股（上季度才入池、无独有订单证据、且价格+流动性双杀）按阈值降 watch。具体：
   - 光模块：中际旭创、新易盛、天孚通信、华工科技、光迅科技、源杰科技、剑桥科技、联特科技、仕佳光子 **保留 core（打标签）**；光库科技、天通股份、德科立、长芯博创 **降 watch**；4 只 watch（福晶/长盈通/罗博特科/太辰光）**剔除**。
   - 存储/HBM：兆易创新、香农芯创、佰维存储 **保留 core（打标签）**；澜起科技（事件利空）、江波龙（双阈值触发）**降 watch**；北京君正 **剔除**。
   - AI-PCB：胜宏/沪电/深南/鹏鼎/生益/兴森/景旺/南亚 **保留 core（打标签）**；德福科技、联瑞新材 **降 watch**；4 只 watch（华正/圣泉/宏和/铜冠）**剔除**。

## 5. 新主题结论：数据中心网络是否新增分类

**不需要"新增"——它已是现存主题（3 只 core：紫光股份、中兴通讯、锐捷网络），但应当扩容。**

- 动作：本方案新入 4 只 watch（星网锐捷、共进股份、菲菱科思、盛科通信-U），使主题达 3 core + 4 watch。
- 不建议新建的其他分类："AI 应用/软件"（金山办公、深信服等候选所示）超出本系统"算力产业链硬件"边界，且与打分器规则体系不兼容，明确拒绝。

## 7. 风险与数据 Caveat 声明

1. **数据源降级**：Tushare 断供（代理 tenant key 2026-07-16 过期），本方案行情来自东方财富/腾讯公开接口 fallback；候选股窗口截至 07-22、成交额为典型价近似值。**Tushare 恢复后应重跑校验全部阈值判定**，尤其是处于阈值边缘的个股（天孚通信 -31.82%/趋势 -21.6%、华工科技 -31.62%/-28.5%、香农芯创 -42.48%/-21.5% 均因"双阈值不同时满足"保留 core）。

3. **拥挤回撤标签未落地**：`crowded_drawdown` 为方案层建议，需打分器侧实现；落地前，三大高景气暴跌主题的 core 股在信号生成中无差别对待，存在左侧接刀风险。

5. **宏观时点**：本方案基于 2026-07-23 收盘信息；7/21 暴力反弹（科创50 +10.73%）显示高波动环境，阈值判定对窗口选择敏感，建议下个观察期（约 4 周）复核全部升降级。
6. **本方案不构成投资建议**；落地动作（修改 universe.json、设置 strategy_from/until 点时生效）应由所有者决策后按 schema 规范执行。
