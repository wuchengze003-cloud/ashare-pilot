## 生产项目允许保留

- `docs/architecture/`：已接受决策、契约目录和职责边界。
- `config/`：通过Schema和黄金样例管理的成本、交易和风险契约。
- `pyserver/`：仍被当前数据合同需要的数据源适配、规范化和质量证明。
- `research/`：当前生产研究、点时回测、策略赛马、组合、适配器和信号生成。
- `web/`：读取版本化生产产物的页面和只读API。
- `ops/`与`.github/`：分阶段运行、校验、发布、回滚和CI门禁。

“允许保留”不是整目录自动通过。每个现有文件仍需证明属于上述职责，混合文件
必须重写或拆开，不能整体复制旧实现。

## 整体进入Legacy

- `reports/`下的日期报告、供应商导出、历史回测和失效赛马结果。
- Momentum-V1、Tide、Prism及其他旧策略实现、注册表、参数优化和专属测试。
- TypeScript回测、优化器、旧策略Dashboard和历史信号展示链路。
- 旧V1/ML影子切换、回滚到V1及旧三策略每日收盘任务。
- 把`web/data/universe.json`作为交易股票池的编辑、刷新和执行逻辑。
- 旧品牌素材、旧产品说明和只为旧页面服务的样式、测试及脚本。
- 过期runtime、缓存数据库、历史信号快照和手工运行日志。

Legacy保存完整分离前快照，因此无需为了“以后可能有用”在生产树留副本。

## 必须逐文件审核

以下现有区域混合了可复用基础设施和旧产品语义，不能整目录迁移：

| 区域 | 审核问题 |
|---|---|
| `pyserver/` | 接口是否只提供数据；是否含Tide/Prism专用或无点时语义的端点 |
| `research/ashare_research/` | 是否属于当前生产赛马；是否仍依赖V1、旧AI名单或旧runtime |
| `research/config/` | 是否为当前预注册配置；是否引用Web股票池或失效策略 |
| `web/app/`、`web/lib/` | 是否只展示生产契约；是否重算策略、收益、仓位或fallback |
| `web/scripts/` | 是否只执行单一受控阶段；是否混合刷新、推理、测试、构建和部署 |
| `ops/agents/` | 权限是否机器执行；任务是否引用旧策略、旧runtime或宽泛职责 |
| 根目录启动和部署文件 | 是否使用固定旧路径、共享数据库或隐式启动顺序 |

## 禁止迁移

以下内容不得复制到任一源码仓库：

- `.env`、API密钥、令牌和个人凭证。
- 可重新生成的缓存、依赖目录和构建目录。
- 未经许可的供应商原始数据。
- 不知道来源或尚未保护的未提交修改。

## 迁移顺序

1. 记录原生产仓完整状态，保护未提交工作，确定Legacy分离提交和标签。
2. 创建Legacy本地仓和远程仓，完成敏感信息扫描后设为只读。
3. 在生产分支先删除整体Legacy区域，再处理混合文件，避免长期双轨。
4. 建立契约Schema、黄金样例和禁止依赖CI。
5. 接通唯一Python生产链路和只读Web链路。
6. 完成回放、影子运行、异常演练后才替换现有部署。

## 完成定义

- `git ls-files`中没有历史报告、运行快照或旧策略实现。
- 生产依赖图没有Legacy路径、包、数据库或环境变量。
- 代码搜索在`docs/architecture/PROJECT_SPLIT.md`之外不再出现旧策略作为运行
  分支或fallback。
- 从全新目录仅凭锁文件和环境模板即可构建、测试并启动生产项目。
- 删除本机Legacy目录后，生产项目测试和运行结果不变。
