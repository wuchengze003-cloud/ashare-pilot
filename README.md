# ashare-pilot

面向A股的生产级研究、策略赛马、组合信号和只读产品系统。

## 当前阶段

项目正在执行新旧系统物理拆分。本工作区是生产项目的独立架构分支，尚未完成
源码提纯和生产验收，不应从此分支部署或生成真实交易决策。

旧产品、旧策略、历史Dashboard、历史报告和运行数据将冻结到独立的
`ashare-pilot-legacy` 项目。生产项目不兼容、不调用也不回退到Legacy。

## 生产边界

```text
市场数据 -> Pyserver数据合同 -> Research唯一策略与组合权威
         -> 版本化生产信号 -> Web只读展示

Ops只编排和验证各阶段，不计算策略或仓位。
```

- Python Research是生产回测、策略、组合和信号的唯一计算权威。
- 通用研究和生产候选范围使用交易日当时有效的中证800成员及完整资格门禁。
- Web不包含独立策略、回测、优化器或仓位引擎。
- 无有效冠军、数据过期或契约不一致时执行明确的降级状态，不使用旧策略fallback。
- 历史输出不进入生产源码树；生产证据使用不可变产物、manifest和哈希。

## 合并门槛

架构分支只有在以下条件满足后才能进入生产主线：

1. Legacy分离点、标签和独立仓库经过确认。
2. 原工作区的未提交成果已保护并逐项归属。
3. 禁止路径和跨项目依赖由CI执行，而不是只写在文档中。
4. 生产契约有Schema、黄金样例和消费者测试。
5. 全新目录可独立完成构建、测试、回放和异常演练。

具体安装、测试和运行命令将在源码提纯完成后根据真实生产入口补充；拆分前的
旧命令不会复制到本说明中。
